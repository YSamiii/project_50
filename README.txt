Project XX 打分制手机端 PWA

这是只保留 Project 挑战与 100 分打分功能的手机端版本。

功能：
- 自定义挑战天数，例如 Project 30、Project 50、Project 100
- 修改天数后，应用标题、Day 进度、日历和计划平均分自动更新
- 仅使用 100 分打分制
- 规则分为“必须完成项”和“加分项”
- 必须完成项逐项累计分数
- 多个加分项每天只取已完成项中的最高分，不重复加分
- 自动计算当日总分、已记录天平均分、全部计划天数平均分
- 手机端直接编辑规则名称、图标和分数
- 日历补记、睡眠、心情、每日总结
- 一键恢复默认规则
- JSON 数据导入与导出
- 可添加到 iPhone 或 Android 主屏幕
- 支持离线缓存

安装：
1. 将文件夹内的全部文件上传至 GitHub Pages 或其他 HTTPS 网站，并确保 index.html 位于网站根目录。
2. iPhone：使用 Safari 打开网址 → 分享 → 添加到主屏幕。
3. Android：使用 Chrome 打开网址 → 安装应用 / 添加到主屏幕。

修改挑战天数：
打开“设置”，输入天数并保存。已有打卡数据会保留；日历和平均分会按新的计划天数重新计算。
